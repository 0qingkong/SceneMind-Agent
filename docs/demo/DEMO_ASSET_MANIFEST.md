## Profile B approval record

Before Profile B is called record-ready, a human must add an ignored local `asset-approval.json` containing each chosen filename, SHA-256, owner/source, permission statement and approval date. `verify-demo-assets.ps1 -Profile B` treats its absence as a blocker. The release package contains only placement instructions, never the local images or weight automatically.
