# SceneMind presentation media

This directory stores release-selected presentation sources, not raw recordings.

- `subtitles/` contains reproducible UTF-8 SRT files generated from `docs/demo/SUBTITLE_SCRIPT.md`.
- `screenshots/` accepts only explicitly reviewed captures promoted by `capture-demo-screens.ps1 -Promote -ConfirmSelection`.
- `thumbnails/` accepts only an approved 16:9 export.

Raw captures, browser staging output, voice-over, FFmpeg logs and release archives remain under ignored `.runtime/`. A generated file is not approved merely because a script succeeded. Human privacy, subtitle, screenshot, video and redistribution review remains required.
